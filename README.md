# .github

Portada pública de la organización **[shellaquiles](https://github.com/shellaquiles)**.

GitHub renderiza [`profile/README.md`](profile/README.md) en el Overview de [github.com/shellaquiles](https://github.com/shellaquiles). Quien llega a la org debe poder leer ahí quiénes somos, qué hacemos y qué proyectos públicos existen.

Este repositorio no es un producto de software. El sitio, el blog y el catálogo web viven en [shellaquiles-org](https://github.com/shellaquiles/shellaquiles-org).

## Estructura

```
profile/README.md              ← portada (Overview de la org)
profile/logo_shellaquiles.svg  ← marca
README.md                      ← este archivo
LICENSE                        ← MIT
```

## Cómo editar la portada

Cambia `profile/README.md` y abre un Pull Request. El Overview de la org se actualiza al fusionar en `main`.
